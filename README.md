# LaunchOS

适用于 macOS 26 及以上版本的全屏应用启动器。按快捷键打开应用图标网格，输入名称搜索，或用鼠标和触控板翻页。

## 功能

- 全屏分页网格，默认 **4 行 × 7 列**，支持调整行列数。
- 打开后可直接输入应用名称，按回车启动当前页的第一个搜索结果。
- 支持触控板左右滑动、鼠标左右拖动、底部页码和方向键翻页。搜索框为空时可用方向键翻页。
- 点击空白处或按 `Esc` 收起，应用留在后台等待下次唤起。
- 提供可自定义的全局快捷键和登录时启动选项。
- 提供简体中文界面，全屏过渡遵循 macOS 的「减少动态效果」设置。

## 环境要求

- Apple 芯片 Mac。
- macOS 26 或更新版本。
- 从源码构建需要安装包含 macOS 26 或更新 SDK 的 Xcode 或 Command Line Tools。

## 构建和安装

在源码目录执行：

```sh
./build.command
open LaunchOS.app
```

脚本会在项目目录生成带本地临时签名的 `LaunchOS.app`。日常使用时，可以在访达把它拖到「应用程序」后打开。首次打开会显示全屏网格。

## 快捷键和登录自启动

- 默认用 **`⌥⇧空格`** 呼出或收起 LaunchOS。
- 在右上角齿轮中点击当前快捷键，分别选择修饰键和主键，再保存。若组合键已被系统或其他应用占用，LaunchOS 会保留原设置。
- 若想使用 **`⌘空格`**，先在「系统设置 → 键盘 → 键盘快捷键 → 聚焦」中取消勾选「显示‘聚焦’搜索」，再到 LaunchOS 保存该组合键。
- 在齿轮设置里启用「登录时启动」，macOS 登录后会在后台开启 LaunchOS。

## 开发与贡献

LaunchOS 使用 Swift 和 AppKit。应用发现、搜索和设置均在本机处理，运行时无需联网。

- `main.swift` 包含应用窗口、网格、搜索和全局快捷键逻辑。
- `Resources/` 保存应用清单和图标。
- `build.command` 从源码构建并签名应用包。
